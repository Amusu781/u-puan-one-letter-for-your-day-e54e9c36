One letter for the day: **H**, for "haywire". The day went haywire — every plan, gadget and good intention misfired at once, in that funny, specific way a day goes sideways and you can only laugh at it. The program writes that single letter, and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
